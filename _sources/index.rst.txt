NXP Robotics Documentation
===========================

Welcome to the **NXP Robotics** documentation portal — the single entry point
for building, flashing, and running robotics applications on the NXP Mobile
Robotics platforms. It covers the full stack, from real-time flight and
motion-control firmware to the Linux application processor, on-device AI, and
robotics middleware, all validated together as part of the **NXP Robotics
SDK**.

The platforms documented here span a complete robotics system: the
**MR-NavQ95** i.MX 95 vehicle computer for compute and perception, the
**MR-VMU-Tropic** flight controller, the **MR-MCXN-T1** sensor and I/O node,
and the **MR-ESC-AM32-MCXA133** motor-control ESC. Whether you are bringing up
a board for the first time, integrating a camera or NPU, or wiring nodes
together over ROS2, the guides here walk you through it step by step.

**How to use this portal**

- Start with the :doc:`Robotics SDK Introduction <overview/index>` for a
  high-level tour of the SDK and its supported platforms.
- Check the :doc:`Release Notes <reference/nxp-robotics-sdk-release-notes>` for what changed in
  the current release.
- Follow :doc:`Getting Started <sdk/index>` to set up your environment and
  build the SDK.
- Then dive into your board under **Platforms**, and see **System** for topics
  that apply across the hardware.

Use the navigation on the left to browse, or the search box to jump straight
to a topic.
