# Finding platform resources and information on the NXP web site

The information page for the MR-VMU-Tropic flight-controller reference design is on the NXP web site at [https://www.nxp.com/design/design-center/development-boards-and-designs/MR-VMU-TROPIC](https://www.nxp.com/design/design-center/development-boards-and-designs/MR-VMU-TROPIC). The information page provides overview information, documentation, software and tools, and a Getting Started tab with quick-reference information, including the downloadable assets referenced in this document.

The board design files and the latest hardware reference are published in the public NXP Robotics repository at https://github.com/NXP-Robotics/MR-VMU-TROPIC. The software, images, and build tooling are distributed through the NXP Robotic Platforms SDK; follow the [NXP Robotic Platforms SDK README](https://github.com/nxp-robotics/robotics-sdk/blob/robotics-0.7.0/README.md) to set up the SDK and obtain the assets.
