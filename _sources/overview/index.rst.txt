Robotics SDK Introduction
=========================

Welcome to the **NXP Robotics** documentation. This portal brings together the
getting-started, setup, and reference guides for building robotics applications
on the NXP Mobile Robotics platforms (MR-NavQ95, MR-VMU-Tropic, MR-MCXN-T1,
MR-ESC-AM32-MCXA133; i.MX 95, eIQ Neutron NPU, Kinara ARA-240 DNPU, and the
PX4 flight stack).

The **NXP Robotics SDK** provides validated software support across these
platforms, spanning two software domains:

- **Real-Time domain** -- flight- and motion-control firmware (PX4 on NuttX,
  Zephyr RTOS, ESC firmware, System Manager, and the real-time control core).
- **Compute domain (Linux / Application Processor)** -- the application-processor
  software stack (Linux BSP, U-Boot, ROS2, camera and vision pipeline, NPU
  inference, and connectivity).

New here? Head to **Getting Started** to set up and build the SDK, then pick
your platform under **Platforms**.
