# Getting ready

Working with the MR-ESC-AM32 board requires an AM32-supported flight controller and a Windows/Linux PC.

## Kit contents

- MR-ESC-AM32 board
- Quick Start Guide

## Additional required hardware

- An AM32-supported flight controller
- A small-drone BLDC motor, such as a 2212 920 KV motor

## Assumptions

Familiarity with the AM32 online/offline configurator and the [AM32 wiki](https://wiki.am32.ca/).

## AM32 firmware

The MR-ESC-AM32 board is expected to ship pre-flashed. If a firmware update is required, newer releases are available from the official [AM32 downloads page](https://am32.ca/downloads).

- Bootloader: `AM32_A153_BOOTLOADER_PB2_Vxx.hex`
- Main application: `AM32_FRDM_A153_x.xx.hex`

AM32 firmware development is outside the scope of this guide. For development information, refer to the public resources available on the AM32 website and GitHub repository.
