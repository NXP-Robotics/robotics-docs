PX4 Documentation Reference
===========================

PX4 is the open-source software stack that implements the autopilot
functionality running on supported NXP Robotic platforms. On the
MR-NavQ95 it runs on the Cortex-M7 real-time core, while the Cortex-A55
application cores run Linux and the robotics middleware; the two domains
communicate over the on-chip RPMsg/OpenAMP transport. PX4 provides the flight
stack, vehicle setup, sensor calibration, parameter configuration, and
communication interfaces (uORB, MAVLink, and more) that our robotics use cases
build on.

For detailed, version-specific guidance, refer to the official PX4 User Guide
for version 1.17, which covers hardware setup, configuration, flight modes,
development, and troubleshooting:

- `PX4 User Guide (v1.17) <https://docs.px4.io/v1.17/en/>`_
