# MR-MCXN-T1-IO input/output shield

The MR-MCXN-T1-IO is an input/output shield for the MR-MCXN-T1 Hub, fitted with Dronecode standard connectors. It extends the Hub with the I/O interfaces commonly used on drones and mobile robots so that the node can act as a distributed input/output endpoint on the 100BASE-T1 Ethernet fabric.

## MR-MCXN-T1-IO setup and configuration

The shield is enabled through the NXP Robotic Platforms SDK. The MR-MCXN-T1-IO maps to the `io_exp` application and its matching shield overlay, which the SDK injects automatically when building for this configuration. See the [MR-MCXN-T1 Deploy and Run Quick Start](../../getting-started/mr-mcxn-t1-quick-start.md) for the build and flash workflow.
