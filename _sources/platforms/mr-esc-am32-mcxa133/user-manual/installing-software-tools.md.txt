# Installing and configuring software tools


1. Download the latest firmware from the [AM32 downloads page](https://am32.ca/downloads):
   - Bootloader: `AM32_A153_BOOTLOADER_PB2_Vxx.hex`
   - Main application: `AM32_FRDM_A153_x.xx.hex`
2. Connect the JST 6-pin debug connector to a debugger (J-Link, MCU-Link, etc.).
3. Power up the board, either via battery or PSU (2S–6S).
4. Flash both HEX files to the MR-ESC-AM32 board.
