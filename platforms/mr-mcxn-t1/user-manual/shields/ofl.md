# MR-MCXN-T1-OFL optical-flow shield

The MR-MCXN-T1-OFL is an optical-flow shield for the MR-MCXN-T1 Hub. It combines a distance sensor with an optical-flow measurement so that the node can provide velocity and altitude-aid data to a flight controller or ROS 2 system over the 100BASE-T1 Ethernet fabric.

## MR-MCXN-T1-OFL setup and configuration

The shield is enabled through the NXP Robotic Platforms SDK. The MR-MCXN-T1-OFL maps to the `optical_flow` application and its matching shield overlay, which the SDK injects automatically when building for this configuration. See the [MR-MCXN-T1 Deploy and Run Quick Start](../../getting-started/mr-mcxn-t1-quick-start.md) for the build and flash workflow.
